# Comic Age Rating ML Project

## Problem
Predict the age rating of comic books using machine learning.

## Dataset
Comic Books Dataset (10000 entries)

## Features
- Release Year
- Page Count
- Genre
- Format
- Country
- Language
- Status

## Models
- Logistic Regression
- Decision Tree
- Random Forest
- KNN

## Deployment
Streamlit web application
